# Security and responsible disclosure

Use GitHub private vulnerability reporting for this repository to report an issue. The tool deliberately has no network calls and does not execute untrusted links. Its default check command redacts all original URL values from reports, but link values supplied directly as arguments might remain in shell history, process listings or logs outside our control. Build and strip intentionally print an output URL, so review output before sharing. Do not disclose real secrets in public issues. No bounty or response SLA is promised.
